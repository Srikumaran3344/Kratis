# Kratis
A 2D pixel-art game project built with JavaScript and the MAKI framework.

The name Kratis is inspired by the Greek word Kratos, meaning power, strength, and sovereignty.
Project Status

This project has been discontinued.

During development, I ran into major limitations and technical issues with the MAKI tilemap system and editor pipeline. While the framework was beginner-friendly and easy to set up, the lack of flexibility and recurring map/rendering problems made it difficult to properly implement the core game systems and world design I had planned.

Rather than forcing the project forward on a weak technical foundation, I decided to stop development and treat it as a learning experience instead.

Although the game itself was never completed, the project helped me learn:

Basics of 2D pixel game development
Tilemaps and collision systems
Sprite and asset pipelines
Working with JavaScript game frameworks
The importance of tooling and engine limitations in game development

There is currently no playable build or demo available.

Thank you for checking out the project.
